=========================================================
INSTRUCCIONES DE DESPLIEGUE EN PYTHONANYWHERE (GRATUITO)
=========================================================

ESTE ARCHIVO CONTIENE LOS 7 PASOS A SEGUIR EN PYTHONANYWHERE

====================================================================
PASO 1: SUBIR EL CODIGO A PYTHONANYWHERE
====================================================================

Opción A (Git):
  1. En PythonAnywhere, abre una consola Bash
  2. Clona tu repositorio:
     git clone https://github.com/TU_USUARIO/Paz-y-Salvo.git
  3. Esto crea la carpeta ~/Paz-y-Salvo/

Opción B (Subir archivos):
  1. Comprime la carpeta "pazysalvo" (la que contiene manage.py)
  2. Ve a la pestana "Files" en PythonAnywhere
  3. Sube el .zip
  4. En la consola: unzip nombre.zip
     (esto crea ~/pazysalvo/ con manage.py adentro)


====================================================================
PASO 2: CREAR BASE DE DATOS MYSQL
====================================================================

  1. Ve a la pestana "Databases" en PythonAnywhere
  2. En "MySQL databases", ingresa una contrasena y crea la BD
  3. Anota estos datos que apareceran:
     - Database name:     TU_USUARIO$default (o TU_USUARIO$pazysalvo si
                          elegiste ese nombre)
     - Database username: TU_USUARIO
     - Database password:  (la que pusiste)
     - Host: TU_USUARIO.mysql.pythonanywhere-services.com
  4. Guarda estos datos, los necesitaras en el PASO 4


====================================================================
PASO 3: IMPORTAR LOS DATOS DESDE LA BASE LOCAL
====================================================================

  1. En tu computadora local, exporta tu base MySQL:
     Opcion A: Usando el script scripts/exportar_db_local.bat
     Opcion B: Con phpMyAdmin, exporta la BD como SQL
     Opcion C: Con MySQL Workbench, Data Export
     Opcion D: Directo en consola:
       mysqldump -u root -p pazysalvo > pazysalvo_dump.sql

  2. Sube el archivo pazysalvo_dump.sql a PythonAnywhere (pestana Files)

  3. En la consola Bash de PythonAnywhere, importa:
     mysql -h TU_USUARIO.mysql.pythonanywhere-services.com \
           -u TU_USUARIO -p \
           TU_USUARIO$pazysalvo < pazysalvo_dump.sql


====================================================================
PASO 4: CONFIGURAR settings_production.py CON TUS DATOS
====================================================================

  Edita el archivo:
    ~/Paz-y-Salvo/pazysalvo/pazysalvo/settings_production.py

  Cambia estos valores (usa los datos del PASO 2):

    SECRET_KEY = 'genera-una-clave-aleatoria-segura'

    ALLOWED_HOSTS = ['TU_USUARIO.pythonanywhere.com']

    DATABASES = {
        'default': {
            'ENGINE': 'django.db.backends.mysql',
            'NAME': 'TU_USUARIO$pazysalvo',
            'USER': 'TU_USUARIO',
            'PASSWORD': 'tu-contrasena-mysql',
            'HOST': 'TU_USUARIO.mysql.pythonanywhere-services.com',
            'PORT': '3306',
        }
    }

  Para generar una SECRET_KEY segura, corre esto en la consola Bash:
    python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"


====================================================================
PASO 5: CREAR ENTORNO VIRTUAL E INSTALAR DEPENDENCIAS
====================================================================

  1. En la consola Bash de PythonAnywhere:
     mkvirtualenv --python=/usr/bin/python3.10 pazysalvo

  2. Instalar dependencias:
     cd ~/Paz-y-Salvo/pazysalvo
     pip install -r requirements.txt

  3. Opcional: si Django 6.x no esta disponible, especifica la version:
     pip install "Django>=5.1,<6.0"
     pip install pymysql pandas openpyxl


====================================================================
PASO 6: CONFIGURAR LA WEB APP
====================================================================

  1. Ve a la pestana "Web" en PythonAnywhere
  2. "Add a new web app"
     - Siguiente
     - Elegir "Manual configuration"
     - Python 3.10
     - Siguiente (crea la app)

  3. En la seccion "Code":
     - Working directory:   /home/TU_USUARIO/Paz-y-Salvo/pazysalvo
     - WSGI configuration file:
       Haz clic en el link para editar

       PONER ESTE CONTENIDO (reemplaza todo):

import os
import sys

path = '/home/TU_USUARIO/Paz-y-Salvo/pazysalvo'
if path not in sys.path:
    sys.path.append(path)

os.environ['DJANGO_SETTINGS_MODULE'] = 'pazysalvo.settings_production'
os.environ['PYTHON_EGG_CACHE'] = '/home/TU_USUARIO/.python-eggs'

from django.core.wsgi import get_wsgi_application
application = get_wsgi_application()

     (Recuerda cambiar TU_USUARIO por tu usuario real)

  4. En la seccion "Virtualenv":
     - Poner la ruta: /home/TU_USUARIO/.virtualenvs/pazysalvo

  5. En la seccion "Static files":
     - URL: /static/
     - Path: /home/TU_USUARIO/Paz-y-Salvo/pazysalvo/staticfiles/
     (Luego en el PASO 7 vamos a generar esa carpeta)


====================================================================
PASO 7: COLECTAR ARCHIVOS ESTATICOS
====================================================================

  En la consola Bash de PythonAnywhere (con el virtualenv activado):

    cd ~/Paz-y-Salvo/pazysalvo
    python manage.py collectstatic

  Responde "yes" si pregunta.


====================================================================
PASO 8: EJECUTAR MIGRACIONES Y DATOS INICIALES
====================================================================

  En la consola Bash de PythonAnywhere (con el virtualenv activado):

    cd ~/Paz-y-Salvo/pazysalvo
    python manage.py migrate --settings=pazysalvo.settings_production
    python manage.py seed_data --settings=pazysalvo.settings_production

  Esto crea las tablas de Django admin (auth.User, etc.)
  y ejecuta el seed con los datos iniciales.


====================================================================
PASO 9: CREAR SUPERUSUARIO (OPCIONAL, PARA /ADMIN/)
====================================================================

  Opcional, solo si quieres usar el admin de Django:

    cd ~/Paz-y-Salvo/pazysalvo
    python manage.py createsuperuser --settings=pazysalvo.settings_production


====================================================================
PASO 10: REINICIAR Y PROBAR
====================================================================

  1. Ve a la pestana "Web" en PythonAnywhere
  2. Haz clic en el boton verde "Reload" (arriba a la derecha)
  3. Espera unos segundos
  4. Abre: https://TU_USUARIO.pythonanywhere.com/
  5. ¡Deberia funcionar!


====================================================================
NOTAS IMPORTANTES
====================================================================

- El sitio se "duerme" a los ~30 min sin actividad. El primer request
  del dia tarda 5-10s en responder (mientras "despierta").

- Los 100s de CPU son un soft limit: si los excedes, la app se
  ralentiza pero NO se bloquea. Se restablece cada dia.

- Para actualizar el codigo luego de cambios:
    1. git pull (o subir archivos de nuevo)
    2. python manage.py collectstatic --noinput
    3. Reload la web app

- Las contraseñas de usuarios en Login model usan PBKDF2 en settings.py
  original. En produccion se usa el mismo algoritmo.

- Si ves errores de "No module named pymysql", verifica que el
  virtualenv este activado al instalar.
